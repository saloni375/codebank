# CodeBank – Digital Banking App (Frontend)

A net-banking simulation frontend with account dashboards, fund transfers, and loan and credit card application flows.

## Features
- Login and signup with JWT-based authentication
- Account dashboard with balance and transaction history
- Charts for balance and transactions using Chart.js
- Fund transfer, loan application, and credit card application forms
- Global auth state with React Context API

## Tech Stack
React.js, Vite, Tailwind CSS, Material UI, Chart.js, Axios

> Note: This repo contains the frontend only. It connects to a separate backend through REST APIs.

## Run Locally
```bash
npm install
npm run dev
```
